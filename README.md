# Luna

Launcher Minecraft pour un groupe prive.

- Connexion par pseudo hors-ligne ou par compte Microsoft.
- Un seul bouton Play, qui lance la version et les mods definis par l'auteur.
- Mise a jour automatique : les mods ajoutes arrivent sans action de l'utilisateur.

## Etat

En developpement, phase 0. Rien n'est encore fonctionnel.

## Stack

.NET 10, WPF, CmlLib.Core.

## Build

    dotnet build
    dotnet run --project src/Luna
